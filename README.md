# Agentic-AI-n8n-Demos

This repository contains a curated set of hands-on lab demos focused on Agentic AI workflows, workflow automation with n8n, and Explainable AI (XAI) techniques.

The material is organized into two main sections:

## 1. n8n Demos
These labs demonstrate how to build intelligent, autonomous, and task-driven workflows using n8n with AI agents and automation patterns.

Included lab files:
- Agentic-AI-Lab-1.md
- Agentic-AI-Lab-2.md
- Agentic-AI-Lab-3.md
- Agentic-AI-Lab-4.md
- Agentic-AI-Lab-5.md
- n8n-Simple-Student-AI-Agent-Demos.md

These resources cover practical examples of chaining AI tools, building reusable agent flows, and creating student-friendly automation demos with n8n.

## 2. XAI Demos
These labs focus on understanding and explaining model behavior using interpretability methods for machine learning and deep learning models.

Included lab files:
- Lab-1-Occlusion.md
- Lab-2-Grad-CAM.md
- Lab-3-DeepSHAP-DeepLIFT.md
- Lab-4-Counterfactual-Explanations.md
- Lab-5-Integrated-Gradients-on-LSTM.md
- Lab-6-Transformer-Token-Attribution.md

These walkthroughs explore techniques such as occlusion analysis, Grad-CAM, SHAP, DeepLIFT, counterfactual explanations, integrated gradients, and transformer token attribution to explain model decisions.

## Repository Purpose
The goal of this repo is to provide accessible, practical exercises for learning:
- Agentic AI design patterns and automation
- Workflow orchestration with n8n
- Explainability and interpretability in AI systems
- Building demos and lab exercises for experimentation and teaching

## Suggested Learning Flow
- Start with the n8n demo labs to understand workflow-based AI automation.
- Move to the XAI labs to inspect and explain how model outputs are generated.
- Combine the ideas to build more transparent and agentic AI systems.

This repo is intended as a reference and learning workspace for experimentation, educational demos, and AI workflow prototyping.
